Certainly. The primary reason relates to memory access patterns.

Quick Sort relies heavily on random access to elements to efficiently partition the array. Arrays support O(1) random access. Linked lists, however, do not; accessing an element requires sequential traversal.

// Array: O(1) access
int val = arr[5];

// Linked List: O(n) access
Node curr = head;
for(int i=0; i<5; i++) curr = curr.next;

Merge Sort operates strictly sequentially, making it highly efficient for linked structures where we only need sequential access to split and merge.
